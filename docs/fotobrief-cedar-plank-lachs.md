# Fotobrief: Cedar-Plank-Lachs (Eigenfoto Uwe)

**Ziel:** Lachsseite AUF sichtbar verkohlter Zedernplanke, gegart, auf dem Grill.
Wird das erste Rezeptbild mit `imageAI: false` — kein Edit nötig, nur Grading.

## Vorbereitung
- Zedernplanke 1–2 h wässern (verhindert Vollbrand, erzeugt Rauch)
- Lachsseite MIT Haut auf die Planke, Rub/Gewürze sichtbar auftragen (Textur!)
- Direkt vor dem Foto dünn mit Öl bepinseln → appetitlicher Glanz
- Grill: indirekte Zone, Deckel zu bis kurz vor Garende

## Der Foto-Moment
- **Bestes Fenster: letzte 5 Minuten der Garzeit** — Lachs opak/leicht gebräunt,
  Plankenränder deutlich verkohlt. Zweite Chance: frisch vom Grill auf rustikalem Holzbrett.
- Für sichtbaren Rauch: eine Handvoll gewässerte Räucherchips 2–3 Min. vor dem Foto auf die Glut.

## Licht (wichtigster Faktor)
- **Nur Tageslicht.** Ideal: früher Abend/goldene Stunde oder gleichmäßig bewölkt.
- Licht seitlich oder leicht von hinten (Gegenlicht macht Rauch sichtbar). 
- KEIN Blitz, keine harte Mittagssonne von oben, kein Kunstlicht.

## Perspektive & Technik
- Kamera etwa auf Rost-Höhe, leicht schräg von vorn (30–45°) — die Planke muss
  als Planke erkennbar sein (Längskante + verkohlter Rand im Bild).
- **Querformat**, Motiv mit etwas Luft drumherum (wir schneiden auf 16:10 + 16:9).
- Hauptkamera des Handys (nicht Ultraweit — verzerrt), Fokus auf den Lachs tippen,
  RAW/„Pro" falls vorhanden, sonst normal. 
- **Serie schießen: 15–20 Bilder**, leicht variierte Winkel/Abstände — wir wählen aus.

## Vermeiden
- Markenlogos im Bild (Grill-Deckel-Logo!), Hände/Personen, Zange im Bild,
  unruhiger Hintergrund (Gartenmöbel, Plastik). Hintergrund dunkel/ruhig halten.
